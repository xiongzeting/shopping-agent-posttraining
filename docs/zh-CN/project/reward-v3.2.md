# Reward v3.2（历史合同）

Reward v3.2 是 Reward v4 之前使用的冻结历史合同。历史 SFT、Probe 和已完成评测
仍保留该版本标记，不会被重新标注。

其主要终局基础分为：Gold `1.00`、有效替代 `0.80`、部分替代
`-0.30 + 0.50 × S`、合理停止 `-0.15`、过早停止 `-0.35`、最大步数
`-0.50`、循环 `-0.65`、错误购买 `-0.85`。当时类目与价格均属于购买硬门槛，
且尚未启用 Reward v4 的累计步数惩罚。

当前新运行统一使用 [Reward-v4.md](Reward-v4.md)。
